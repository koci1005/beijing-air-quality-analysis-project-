# Beijing Air Quality Data Analysis — GitHub Pages Live Demo

A polished interactive presentation layer for the CV project:
> Analysed Beijing air-quality data in Python to examine pollution patterns and environmental trends.

## Interaction
Visitors can upload a real CSV locally in the browser, choose a numeric column, and view:
- valid-value count
- mean
- median
- min/max range
- a simple row-order trend chart
- first-row data preview

No synthetic Beijing pollution data is bundled.

## Publish
1. Create a public repository named `beijing-air-quality-analysis`.
2. Upload all files in this folder to the repository root.
3. Commit.
4. Open **Settings → Pages**.
5. Choose **Deploy from a branch**.
6. Select `main` and `/ (root)`.
7. Save.

Expected URL:
`https://YOUR-USERNAME.github.io/beijing-air-quality-analysis/`

## Recommended later improvement
Add the exact original dataset citation and the verified Python notebook to the repository, then link them from the page.
